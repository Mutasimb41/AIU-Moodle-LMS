# AIU Moodle LMS Requirements Engineering

## Project Overview
This repository contains the Requirements Engineering analysis for the AIU Moodle Learning Management System (LMS). The project documents functional and non-functional requirements, stakeholder analysis, use case modelling, prioritisation, and traceability management for the system.

The purpose of this repository is to provide a structured, organized, and version-controlled documentation of the AIU Moodle LMS requirements to support academic analysis and reporting.

---

## Repository Structure

- **Wiki**: Contains structured documentation for:
  - Stakeholder Analysis
  - Functional Requirements
  - Non-Functional Requirements
  - Use Case Modelling
  - Traceability Matrix

- **Diagrams**: Includes UML use case diagrams created using Draw.io.

- **Docs**: Contains report-related files, screenshots, and evidence of requirements organization (Trello, ReqView, GitHub Wiki).

---

## Tools Used

- **Draw.io**: For creating UML Use Case Diagrams.
- **Trello**: For organizing requirements and tasks.
- **GitHub Wiki**: For centralized documentation and version control.
- **ReqView**: For requirements management and traceability tracking.

---

## Features

- Organized and documented functional and non-functional requirements.
- UML use case diagrams illustrating system actors and interactions.
- MoSCoW prioritisation of requirements.
- Traceability matrix linking requirements to use cases.
- Screenshots and evidence of tool usage for academic reporting.

---

## Usage

1. Navigate through the **Wiki** to view organized requirements, stakeholders, use cases, and traceability links.
2. Check the **Diagrams** folder for UML diagrams.
3. Review the **Docs** folder for screenshots and evidence of RE tool usage.
